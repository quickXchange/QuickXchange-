> ### Dynamic XML Percentage Adjustment
>
> Add a new configurable feature for the XML conversion output.
>
> When an order is active, the XML conversion function should apply the admin-configured **Active Order %**.
>
> When there are no active orders, the XML conversion function should apply the admin-configured **No Active Order %**.
>
> The percentage values must NOT be hardcoded.
>
> Add these settings to the Admin Panel:
>
> - **Dynamic XML Percentage Adjustment:** ON / OFF
> - **Active Order %**
> - **No Active Order %**
>
> ### ON/OFF behavior
>
> **When ON:**
>
> - Active order → apply `Active Order %`
> - No active order → apply `No Active Order %`
>
> **When OFF:**
>
> - Do not apply either percentage.
> - Return the normal/base XML conversion value using the existing XML logic.
> - Do NOT disable the XML feed itself.
>
> Keep the saved percentage values when the feature is OFF so they can be reused when it is turned ON again.
>
> ### Example
>
> Active Order % = 5%  
> No Active Order % = 2%  
> Base value = 100
>
> Feature ON + Active order → XML value = 105  
> Feature ON + No active order → XML value = 102  
> Feature OFF → XML value = 100
>
