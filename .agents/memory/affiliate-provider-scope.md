---
name: Affiliate provider scope
description: Keep affiliate-program provider toggles distinct from operational provider integrations.
---

The Provider Settings expander within Admin Program Settings includes only affiliate-specific provider toggles. The separate Providers & API Integrations Admin area must remain accessible through its own navigation and permission boundary.

**Why:** The user explicitly clarified that only the affiliate toggles should move into Referral. The operational provider page has different settings and permissions; relocating or hiding it could remove access to diagnostics and configuration.

**How to apply:** When reorganizing affiliate Program Settings, group its provider toggles with Referral, but do not merge or remove the global provider operations page unless separately requested.
